> **TaskFlow** is an elegant, keyboard-friendly personal task management application engineered for speed, focus, and clarity. Organize your daily priorities, project milestones, and personal to-dos with zero friction.

---

## 🌟 Key Features

- **📑 Smart Filter Views**:
  - **All Tasks**: Centralized workspace overview.
  - **Today**: Focus specifically on actionable tasks scheduled for today.
  - **Upcoming**: Plan ahead with chronological scheduling.
  - **Starred / Important**: Pin high-priority tasks and critical deadlines.
  - **Completed**: Review your productivity history and completed work.
- **⚡ Quick-Add Task Engine**:
  - Rapidly capture tasks on the fly with smart priority badges, category tags, and due date pickers.
- **📝 Comprehensive Task Modal**:
  - Add detailed notes, nested subtask checklists, tags, and customizable priority levels (Low, Medium, High, Urgent).
- **⌨️ Power-User Keyboard Shortcuts**:
  - Designed for hands-on-keyboard workflows: quick-add shortcut, view toggling, status switching, and instant search.
- **💾 Offline & Local Storage**:
  - All tasks and preferences stay securely stored on your device via browser `localStorage`. No server dependencies, instant startup.

---

## 🛠️ Tech Stack

- **Markup**: HTML5 Semantic Structure
- **Design System**: Modern CSS3 (CSS Variables, Flexbox, Fluid Grids, Responsive Breakpoints, Dark Accents)
- **Logic**: Vanilla JavaScript (Task State Management, Filter Algorithms, LocalStorage API, Keyboard Event Listeners)
